# Frogtome (WoW)

Froey's Game Tools for Organization, Management, and Efficiency (v1.0.0 BETA)

> [!WARNING]
> Frogtome is in early, active development. This is NOT a finished nor robust project and will see many changes from now until its 1.0 release.

This is a World of Warcraft addon that provides various in-game tools for the sake of gathering and viewing information. The focus is on improving the general experience of managing multiple characters on one account, making it so that you don't have to hop onto each individual character or keep a separate document/spreadsheet of notes, however live character data tools are also available to help inform the player and improve gameplay experiences with actual individual characters.

At its core, Frogtome is about characters - individually and collectively - and helping you the player get the most out of your experience with your characters.

## Installation

> [!NOTE]
> Frogtome currently only supports World of Warcraft: Forever (WoWF).

Frogtome is not currently distributed via any addon management service, nor is it public on GitHub. To install Frogtome, you must install it manually using a `.ZIP` file.

### Step 1: Download

Download the Frogtome package as a `.ZIP` file (`frogtome_wow.zip`). This will need to be provided to you directly, as Frogtome is currently not being distributed in any automatic way.

### Step 2: Manual Installation

Once downloaded, unzip the contents and move the contained `frogtome_wow` directory into your World of Warcraft version's addon folder. This path will look something like `[install_path_for_wow_version]/Interface/Addons`.

After this, simply launch the game or, if already open, reload the interface using `/reload`.
